# 食事カレンダー

[アプリを開く](https://kqede0113.github.io/meal-calendar/)

2人で食事と金額を記録するカレンダーです。月ごとに2人の合計と、保存した名前ごとの合計を表示します。

## 2人で使う

1. 最初の人がこの端末の名前を入力し、「共有カレンダーを作成」を押します。
2. 「共有」でリンクをコピーし、もう1人に送ります。
3. もう1人はリンクを開き、自分の端末の名前を保存します。
4. 以降は食事を追加するたびに、端末に保存した名前を自動で付けます。

同じ人が別の端末を使う場合は、共有リンクを開いて保存済みの名前を選んでください。名前を変更しても同じ人の過去の記録と合計を引き継ぎます。食事の編集時は元の記録の名前を保持します。

記録の追加・編集・削除は共有され、ページを開いている間は約5秒ごと、またページに戻った時に再取得します。同じ記録が別端末で変更された場合は上書きを止めて通知します。通信失敗時は保存完了として扱いません。

## 保存と共有

食事記録と2人の名前は非公開の共有データベースに保存します。公開GitHubリポジトリにはコードだけを保存します。ブラウザには共有設定と、この端末で使う名前の選択を保存します。

共有リンクには読み書きのための鍵が含まれます。リンクは一緒に使う相手だけに送ってください。鍵の生データはサーバーのデータベースに保存せず、ハッシュ値で照合します。APIの読み書きには毎回鍵の検証が必要です。

旧バージョンで端末内に記録した食事は、共有設定後に表示される「以前の記録を共有」で移せます。移す際はこの端末で選んだ名前を自動で付けます。元の記録は消しません。

## 開発

Node.js 24以上。追加パッケージは不要です。

```sh
npm run dev
npm test
```

`http://localhost:3000` で静的UIを確認できます。本番共有APIのブラウザ接続元はGitHub Pagesに限定しています。ローカルのAPIテストではNodeのSQLiteを使います。

## 配信

GitHub Pages: `main` ブランチの `/docs` を配信します。APIコードは `backend/worker/index.js`、SQLマイグレーションは `backend/drizzle/` です。APIはD1の `DB` バインディングがあるWorker環境で配信します。鍵やトークンを公開ソースに設定する必要はありません。
