# 食費カレンダー

[アプリを開く](https://kqede0113.github.io/meal-calendar/)

2人で使う、買った日と金額だけのカレンダーです。月の合計と、それぞれの合計を表示します。

## 使い方

1. 初めて開いたら名前を入力します。登録済みならその人として入り、未登録なら2人まで登録できます。
2. 「共有」からリンクをコピーして、もう1人に送ります。
3. 相手も自分の名前で入ります。別端末では同じ共有リンクを開き、同じ名前を入力します。
4. 日付をタップし、買った日と金額を記録します。名前は端末から自動で付きます。

朝・昼などの分類や料理名の入力はありません。右上の名前から使う人を切り替えられます。名前の切り替えは登録済みの人として入る操作で、他の人の名前や過去の記録を変更しません。登録できる名前は2人分です。次回からはそのブラウザで選んだ名前を自動で使います。ブラウザの保存データを消した場合も、同じ共有リンクと名前で入り直せます。

同じ記録の同時編集は上書きを止めて通知します。追加・編集・削除と合計は約5秒ごと、またページに戻った時に共有側から再取得します。

食費と名前は非公開の共有データベースに保存します。公開GitHubにはコードだけが保存されます。共有リンクは一緒に使う相手だけに送ってください。共有リンクには端末の識別情報を含めません。共有リンクを持つ2人が名前だけで使う簡易ログインです。

旧バージョンの名前、名前のID、記録とその入力者・金額・日付は保持します。以前の端末のログインもそのまま使えます。端末内だけに保存していた記録は、共有開始後に「以前の記録を共有へ移す」で取り込めます。

## 開発

Node.js 24以上。追加パッケージ不要。

```sh
npm run dev
npm test
```

GitHub Pagesで `main` の `/docs` を配信します。共有APIは `backend/worker/index.js`、スキーマは `backend/drizzle/` です。本番のブラウザ接続元はGitHub Pagesに限定しています。ローカルAPIテストではNodeのSQLiteを使います。
