# 食事カレンダー

日付を選んで食事名と金額を入力し、月の食費合計を確認するアプリです。

- 月カレンダーと月の食費合計
- 日ごとの食事の追加・編集・削除（朝食・昼食・夕食・間食）
- スマートフォン対応

記録は利用しているブラウザの localStorage に保存します。同じ端末・同じブラウザ・同じURLで利用してください。端末間同期はありません。ブラウザのサイトデータを消すと記録も消えます。食事の記録はGitに含まれません。

## 起動

Node.js 20以上。追加パッケージは不要です。

```sh
npm run dev
```

http://localhost:3000 を開きます。

## 確認

```sh
npm test
```

## 配置

`dist/` を静的サイトとして配信します。ビルドは不要です。
